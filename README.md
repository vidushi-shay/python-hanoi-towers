# Hanoi Towers Game
A console-based implementation of the Tower of Hanoi puzzle written in python.
## Description 
This project allows users to play the Tower of Hanoi game through a console interface where the users can choose the number of towers and disks, move disks according to the rules, and save/load game progress using python's pickle module.
## Files
'hanoi_towers_milestone_1.py' - Main game file containing the game logic and user interactions
'stack.py' - Stack data structure used to manage towers
